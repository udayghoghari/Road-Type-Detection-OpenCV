# Road Type Detection Using OpenCV and CNN

## Overview

This project focuses on identifying different road categories from image data using computer vision and image classification techniques.

## Road Categories

* Highway Road
* Tar Road
* Kacha (Dirt) Road

## Technologies Used

* Python
* OpenCV
* TensorFlow
* Keras
* NumPy
* Jupyter Notebook

## Features

* Road image analysis
* Road type classification
* Image preprocessing
* CNN-based experimentation
* OpenCV-based image processing

## Project Files

* HIGHWAY ROAD.ipynb
* TAR ROAD.ipynb
* KACHA ROAD.ipynb
* Untitled.ipynb

## Note

This project was developed as part of academic learning and experimentation in computer vision and machine learning.
